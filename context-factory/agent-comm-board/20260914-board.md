## Background

The Context Agent panel in `tests/stt-test.html` currently shows only
`provider_name`, `service_name`, and `issue_category` after extraction.
There is no support contact information (email, phone, support URL) anywhere
in the data model. The Contact Agent composes a draft but has no channel to
address it to.

Support contact details cannot be extracted from speech — they must come
from a static provider registry lookup that runs after extraction. The LLM
extraction prompt is not changed.

## Objective

Add a `ProviderSupportInfo` registry, hydrate `CaseData` with support
contact fields after extraction, surface them in the Context Agent panel,
and thread them into the draft. Work only in `ai_engine/` and
`tests/stt-test.html`. Do not change `ExtractionResult` or the
`CaseIntelligenceService` protocol.

## Data flow

```
Speech / case_text
  → LLMCaseIntelligenceService.extract()   [unchanged]
  → apply_extraction()
      → ProviderRegistry.lookup(provider_name)   [NEW]
      → repository.update_case(..., support_email=..., ...)   [NEW]
  → CaseData (with support_email, support_phone, support_url)
  → Context Agent panel   [shows support contact block]
  → Draft prompt          [includes support email/URL]
```

## Required changes

### 1. `app/services/providers/registry.py` (new file)

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class ProviderSupportInfo:
    name: str
    support_email: str | None = None
    support_phone: str | None = None
    support_url: str | None = None
```

Define `PROVIDER_REGISTRY: dict[str, ProviderSupportInfo]` keyed by
**lowercase normalised** provider name. Seed with at minimum:

| Key | name | support_email | support_phone | support_url |
|-----|------|--------------|--------------|------------|
| `"converge ict"` | `"Converge ICT"` | `"support@converge.com.ph"` | `"1-800-1888-8388"` | `"https://www.converge.com.ph/support"` |
| `"pldt"` | `"PLDT"` | `"pldthomecare@pldt.com.ph"` | `"171"` | `"https://pldthome.com/contact"` |
| `"globe"` | `"Globe Telecom"` | `"globe@customer.globe.com.ph"` | `"211"` | `"https://www.globe.com.ph/help"` |
| `"sky cable"` | `"Sky Cable"` | `"mysky@sky.com.ph"` | `"1-800-10-759-4759"` | `"https://www.mysky.com.ph/contact"` |

Implement a module-level function:

```python
def lookup(provider_name: str | None) -> ProviderSupportInfo | None:
    """Return support info for the provider, or None if not in the registry.

    Matching is case-insensitive. A partial match is attempted when an exact
    normalised key is not found — e.g. "Converge" matches "converge ict".
    """
```

Normalisation: `provider_name.strip().lower()`. Exact key match first;
if not found, iterate keys and return the first key that is a substring
of the normalised name or vice-versa (partial match).

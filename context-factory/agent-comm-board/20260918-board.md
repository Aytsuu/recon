# Architecture: Serverless client split — Supabase CRUD + ai_engine voice/LLM

**From:** Plan executor (Cursor Agent)
**To:** Team
**Status:** Implemented (uncommitted)

## Topology

```text
apps/web
  ├─ supabase-client.ts   → CRUD (cases, clarifications, draft edits, search)
  ├─ ai-engine-client.ts  → transcription-token, process-voice, process
  └─ AssemblyAI WebSocket  → browser PCM16 streaming (not ai_engine)

ai_engine (FastAPI)
  ├─ POST /api/cases/{id}/transcription-token
  ├─ POST /api/cases/{id}/process-voice   → transcript + extract + registry + draft → Supabase
  ├─ POST /api/cases/{id}/process          → typed cases: extract + draft → Supabase
  └─ SupabaseCaseRepository (service role) when SUPABASE_URL + SUPABASE_SERVICE_ROLE_KEY set

Supabase
  └─ support_case, case_clarification, support_draft (+ support_email/phone/url columns)
```
